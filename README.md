# SAHRAB Advertising Bot

Starter Telegram advertising bot: Hausa menu, advert submission, packages, Telegram Stars payment, SQLite records, and admin notification.

## Secrets
Set BOT_TOKEN and ADMIN_ID as environment variables. Never publish or send your bot token in chat.

## Deploy
Upload these files to GitHub, then create a Render Worker from the repository. Add BOT_TOKEN and ADMIN_ID as environment variables.

## Packages
Basic 100 Stars; Featured 250 Stars; Premium 500 Stars.

Before launch, add /terms and /support, refund handling, and admin approve/publish buttons. Review Telegram payment rules.
